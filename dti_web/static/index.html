CNN·그래프·3D는 입력을 처리하는 방법이고, IC50·Kd·상호작용 점수는 학습한 예측 대상입니다. IC50로 학습한 CNN이나 그래프 모델도 IC50를 예측할 수 있습니다. 현재 CNN·MPNN 체크포인트의 정확한 예측 대상은 추가 확인이 필요하며, 모든 모델의 conformal 예측 구간은 아직 미보정 상태입니다.
