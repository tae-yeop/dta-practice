목적별 라우팅 예시

목표 아키텍처의 호출 구조

  1. 오케스트레이터 → 입력 프로파일러

    SMILES와 단백질 서열을 식별한다. 실험·구조 조회를 요청한 경우 프로파일러가 공개 DB에서 근거를 가져온다.

  2. 오케스트레이터 → 모델 라우터

    프로파일과 요청 목적을 넘긴다. 라우터는 적용 가능성과 예산을 평가한다. 실험 근거로 답할 수 있는 요청은 여기서 보고한다.

  3. 실행기 → 선택된 모델의 작업자

    모델마다 같은 입력 쌍을 전달한다. 결과 수집기는 성공한 출력과 개별 실패를 모은다. 병렬 실행은 설계안이며 현재 다중 모델 실행은 순차 방식이다.

  4. 오케스트레이터 → 출력 정리·신뢰성 평가

    측정 지표가 같은 결과끼리 비교하고, 예상 오차 범위를 벗어난 충돌을 찾는다.

  5. 충돌 또는 근거 부족 → 검증 계획 에이전트 → 검증 도구

    추가 검사가 필요할 때만 호출한다. 에이전트가 예산 안에서 확인할 항목을 고르고 결과를 오케스트레이터에 돌려준다.

  6. 오케스트레이터 → 결합·보정·보고

    고정된 정책으로 비교 가능한 예측을 결합한다. 예측구간과 판단 근거를 보고하거나 보류 사유를 남긴다.

모델 출력표

DeepPurpose CNN · MPNN
upstream_log_affinity는 배포된 체크포인트가 반환하는 원시 로그 점수다. 어떤 실험 지표를 학습했는지 확인되지 않아 농도 단위로 환산할 수 없다. 현재 라우터는 후보 순위 탐색에 사용한다.
ConPLex
화합물과 단백질을 각각 벡터로 표현한 뒤 코사인 유사도로 상호작용 점수를 계산한다. 결합 확률로 읽으려면 별도의 보정이 필요하다.
Boltz-2
IC50 예측값은 µM 단위 농도의 상용로그다. 값이 낮을수록 예측 IC50이 낮다. 결합 가능성 점수와 복합체 좌표(CIF)는 각각 별도 출력이다. 구조 신뢰도는 좌표에 대한 지표다.
실험값과 비교할 때
같은 표적·측정 지표·단위·척도를 맞추고 실험 조건과 부등호를 확인한다. IC50은 주어진 실험 조건에서 50% 억제에 필요한 농도이고, Kd는 결합 평형의 해리 상수다.
